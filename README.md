# DataHub-Models (Databricks slice)

This GitHub repo holds **only what is needed** to run the marketing SD/STAT → MRGAL prototype on **Databricks**.

- **Pipeline:** `databricks/proto/` — notebooks `src/01`–`07`, `databricks.yml`, sample Parquet **fixtures**, and **`databricks/proto/README.md`** (setup, Git, parameters).

Local-only assets (synthetic generators, transcripts, large CSVs) stay on your machine and are listed in `.gitignore`.
